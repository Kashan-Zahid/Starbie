# Starbie 

Starbie is a small custom hardware project designed from scratch using KiCad. It combines custom PCB design, 3D printing, and firmware into a functional digital Pet.

# Circuit ## 🛠️ Repository Structure

* `*.kicad_sch` & `*.kicad_pcb` — KiCad schematic and board design files
* `gerbers.zip` — Manufacturing files (Gerber + drill files)
* `firmware/` — Code running on the microcontroller
